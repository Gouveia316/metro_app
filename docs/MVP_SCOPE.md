# MVP Scope

## Product Goal

Create a clean, mobile-first Lisbon metro app foundation that can grow into a reliable daily-use transit companion.

## MVP Screens

### Home Screen

- Show a favorite station placeholder.
- Provide a simple summary of mocked service status.
- Keep the first screen calm and useful.

### Lines Status Screen

- Show all Lisbon metro lines.
- Display mocked service status for each line.
- Include concise status notes.

### Station Search/List Screen

- Show a searchable station list.
- Include line badges for each station.
- Link each station to a detail screen.

### Station Detail Screen

- Show station name and served lines.
- Show mocked next train arrivals.
- Leave a clear integration point for real arrival data later.

### Alerts/News Screen

- Show mocked important service alerts.
- Include severity, title, affected lines, and short message.

## Explicitly Out Of Scope For This MVP

- Login or user accounts
- Database storage
- Payments
- Digital pass or NFC
- Push notifications
- Real external API integrations
- Official data provider integration
